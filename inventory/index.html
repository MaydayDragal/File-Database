Legend & notes

These lists define the required M‑B Special Tools — primarily service categories Ct A and B, sometimes C and K — that authorized dealers keep to perform service, maintenance, diagnosis and minor repairs.

MM Maintenance‑Manual tools — required tools specifically described in the M‑B Maintenance Manuals.

R Required tools — additionally designated by DCAG.

A Additional tools — additionally designated by MBUSA.

Ct Service category of the tool (A / B / C / K).

Prices are for reference only and can change; some tools are ISO‑controlled or no longer available new (dealer should already stock them). Workshop equipment from the Standard Service Equipment program is not listed here.
