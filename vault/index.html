File Vault

A private, offline database for your files — documents, videos, photos, PDFs, spreadsheets and text. It runs entirely inside your browser.

  • No admin rights needed. It's a web page — nothing to install on the machine.
  • Everything stays local. Files are stored in this browser's private database on this computer. Nothing is uploaded.
  • Works offline. Once loaded it keeps working with no network.
  • Find fast. Search, filter by type, group into collections and tag anything.
  • Portable. Use Export to save a single backup file you can move to another computer and Import there.

⚠️ Because data lives in this browser profile, clearing the browser's site data will erase the vault. Use Export regularly to keep a backup, and click Request persistent storage to make the browser less likely to evict it.
