======================================================================
  FILE DATABASE - Desktop app (portable, runs from this USB drive)
======================================================================

WHAT THIS IS
  A standalone application - its own window, no web browser. It holds your
  files, LI documents, special-tool inventory and file tools. Nothing is
  installed on the computer and it does NOT need administrator rights.

HOW TO START IT
  Double-click:   File Database.exe

  (The first time, Windows may show a blue "Windows protected your PC"
   box because the app is not code-signed. Click "More info" -> "Run
   anyway". This is the same prompt any small portable app shows.)

WHERE YOUR DATA LIVES
  Everything you add is stored in the "data" folder that appears next to
  "File Database.exe" on THIS drive - not on the computer. Unplug the
  stick and nothing is left behind; plug it into another PC and your data
  is all still here.

  >> Keep the whole folder together and always start the app with
     "File Database.exe" so it uses the data folder on the USB.

MOVING YOUR EXISTING DATA IN
  If you already built a vault in the online (github.io) version, open it,
  use the vault's menu -> "Export / back up vault", save the .fvault file
  onto this USB, then in this app use "Import backup" to load it.

GOOD TO KNOW
  * Use an exFAT- or NTFS-formatted USB stick (old FAT32 sticks cap files
    at 4 GB and can run out of room). A fast USB 3.0 stick helps a lot.
  * Safely eject the drive before pulling it out so nothing is mid-write.
  * Requires 64-bit Windows 10 or 11.

PRIVACY
  Nothing is uploaded anywhere. Everything runs and stays on this drive.
